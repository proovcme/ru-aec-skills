# Исходно-разрешительная документация РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Сформируй доказуемый комплект исходных данных. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

## Полный цикл — для локальной задачи только зависимые пункты

1. Зафиксируй права на участок/объект, кадастровые сведения, границы и полномочия заявителя.
2. Получи применимый градостроительный документ: ГПЗУ либо документацию по планировке территории для соответствующего объекта.
3. Наложи красные линии, ЗОУИТ, сервитуты, охранные, санитарные, водоохранные, приаэродромные и иные ограничения.
4. Собери технические условия и условия подключения; проверь владельца, срок, точки, нагрузки и границы ответственности.
5. Сформируй задания на изыскания и проектирование, специальные согласования и требования владельцев территории/сетей.
6. Для каждого документа зафиксируй реквизиты, источник, срок, территорию действия, противоречия и зависимые решения.
7. Выпусти блокирующие запросы и карту допустимой застройки.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай реестр ИРД, сводный план ограничений, матрицу ТУ, журнал противоречий и заключение о готовности к изысканиям/проектированию.
