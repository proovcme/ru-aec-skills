# Контроль строительства РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Организуй доказательства соответствия работ. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

## Полный цикл — для локальной задачи только зависимые пункты

0. Проверь разрешительный маршрут, утверждённую ПД, актуальную РД, договорные роли и применимость надзора.
1. Сформируй план контроля критических характеристик, скрываемых работ, ответственных конструкций, сетей и испытаний.
2. Проведи входной контроль материалов, изделий, оборудования и сопроводительных документов.
3. Организуй операционный контроль технологии, геометрии, последовательности и временных состояний.
4. До сокрытия работ оформи результаты измерений, испытаний, освидетельствований и геодезического контроля.
5. Регистрируй несоответствия; укажи необходимость приостановки зависимых работ и передай вопрос уполномоченному лицу. Не изображай собственный ответ юридическим предписанием.
6. Для отклонений определи необходимость проектного изменения, повторной экспертизы и корректировки разрешения.
7. Проведи приёмочный контроль и передай доказательства в исполнительную документацию.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай план контроля, матрицу ролей, журналы проверок и несоответствий, реестр изменений и заключение о готовности работ к приёмке.
