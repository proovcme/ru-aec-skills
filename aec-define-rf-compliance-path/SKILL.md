# Правовой маршрут объекта в РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Не начинай с универсального чек-листа. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

## Полный цикл — для локальной задачи только зависимые пункты

1. Установи объект, территорию, правообладателя, вид работ и фактическое содержание вмешательства.
2. Классифицируй объект: ОКС/не ОКС, линейный/нелинейный, производственный/непроизводственный, опасный, технически сложный, уникальный, ОКН и иные специальные признаки.
3. Определи градостроительный режим участка, документацию по планировке, ЗОУИТ и региональные ограничения.
4. Установи требования к СРО, НРС, функциям застройщика, технического заказчика, ГИП/ГАП и подрядчиков.
5. Определи применимость изысканий, ПД/РД, экспертизы, экологических процедур, разрешения, стройнадзора и ввода.
6. Для каждого вывода приведи норму и исключение, если оно применено.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай классификационную карточку, дерево применимости процедур, список компетентных органов, участников, обязательных решений и открытых юридических вопросов.
