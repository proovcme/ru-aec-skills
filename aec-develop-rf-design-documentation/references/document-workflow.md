# Выбор процедуры работы с документами

Это внутренний порядок, не нормативная форма. Дополняй существующие реестры; для небольшой задачи достаточно нескольких записей. Статусы согласуй с регламентом проекта. Не создавай весь комплект отчётов ради локальной правки.

Выбери только процедуры текущей задачи и прочитай каждый выбранный файл полностью:

| Задача | Процедура |
|---|---|
| Приём версии, извлечение размеров, противоречия PDF/BIM | [Исходники](document-intake.md) |
| Организация разработки решения | [Этапы](design-stages.md) |
| Передача задания или закрытие замечания | [Интерфейсы](document-interfaces.md) |
| Изменение ранее разработанного решения | [Ревизии](document-changes.md) |
| Подготовка выдачи и проверка пакета | [Выпуск](document-release.md) |

Не обходи все ссылки по очереди. Прочитанный неизменённый файл повторно не загружай в пределах доступного контекста. Если процедура требует другого ресурса, переходи только при наличии указанного условия.


Инструкции описывают действия в разрешённом объёме. Получение файла не разрешает его перезапись, создание пакета не разрешает внешнюю отправку. Непроверенные подписи и согласования не подставлять.
