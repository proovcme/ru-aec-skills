# Предварительная оценка готовности

Для короткой оценки по описанию или реестру, не для подтверждения соответствия реальных чертежей нормам.

1. Определи цель выдачи: обсуждение, согласование или производство. Ограничения различаются; пригодность для обсуждения не означает пригодность к строительству.
2. По представленным сведениям проверь действующие ревизии, согласованность параметров, статус критических интерфейсов и подтверждение необходимых проверок/согласований. Не додумывай отсутствующие данные.
3. При конкретном препятствии назови его, последствия и минимальные действия для устранения. Не подменяй определение правильного решения механическим выбором самого нового числа.
4. Если по входным сведениям препятствий нет, так и скажи в границах этих сведений. Не выдумывай причины отказа. Различай «по представленному реестру готов» и «лично проверены все файлы».
5. Не подтверждай фактическую отправку, утверждение или подписи, которых не выполнял/не проверял. Не проводи повторный полный нормоконтроль только ради предварительной оценки, если пользователь его не просил и противоречий в подтверждениях нет.

Ответ: статус для указанной цели → конкретные основания → необходимые действия/ограничения. Если пользователь просит фактически проверить или оформить пакет, перейди к соответствующей процедуре из SKILL.md; не используй этот короткий маршрут вместо обязательной проверки.
