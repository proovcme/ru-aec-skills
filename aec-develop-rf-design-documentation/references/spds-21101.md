# ГОСТ Р 21.101: оформление и комплектование

Источники: [официальная карточка ГОСТ Р 21.101-2026](https://protect.gost.ru/gost/details/17bc12e8-6579-4145-b141-56855e772e7f), [текст стандарта](https://normadocs.ru/gost_r_21.101-2026). Для конкретного выпуска сверять редакцию и применимость. Текстовая копия позволяет найти пункт, но геометрию формы проверять по изображению оригинала; не восстанавливать размеры рамок по памяти.

## Маршрут проверки

| Предмет | Источник | Что должно быть проверено |
|---|---|---|
| ПД: состав документов и обозначения | 4.1 | Том/раздел/подраздел, текст и графика идентифицированы и согласованы с составом ПД |
| РД: основные комплекты | 4.2.3–4.2.5 | Базовое обозначение, марка, отдельные документы/комплекты и область сквозной нумерации |
| Прилагаемые и ссылочные документы | 4.2.6–4.2.9 | Не перепутаны категории, шифры и фактический состав передачи |
| Общие данные | 4.3 | Ведомости и указания соответствуют фактическому комплекту |
| Оформление листа | 5.1–5.2, приложения Е, Ж | Формат, рамка, основная надпись, правильное заполнение реквизитов |
| Оси, размеры, отметки, изображения | 5.3 и последующие применимые подразделы раздела 5 | Единицы, привязки, обозначения и ссылки читаемы и однозначны |
| Изменения | раздел 7 | Основание, обозначение изменений, заменённые/добавленные листы и согласованность ведомостей |
| Комплектование | раздел 8 | Титул/обложка/содержание и комплект электронных документов соответствуют выбранному способу оформления |

## Выбор формы до создания таблицы/штампа

- Приложение Б: форма 1 для ведомости листов/графической части; проверять графы «Лист», «Наименование», «Примечание» и соответствие названий листам. Для ведомости спецификаций читать отдельные правила заполнения, не копировать смысл граф механически.
- Форма 2 используется для ведомостей документов, в том числе ссылочных/прилагаемых; содержание нескольких документов в томе — по 8.1.5. Проверять обозначение, наименование и примечание. Не подменять ею профильную спецификацию оборудования.
- 5.2.2 и приложение Е: форма 3 — основной выбор для листов основных рабочих комплектов и графики ПД; для строительных изделий, первых/последующих текстовых листов выбирать соответствующую форму по назначению документа.
- 5.2.3: текстовый документ без титула — первый лист с формой 3, последующие с формой 6. Исключения для последующей графики проверять по условиям 5.2.2, не применять форму 6 ко всем листам автоматически.

Для каждой создаваемой формы составить паспорт: `стандарт/пункт/форма | назначение | источник изображения | размеры | графы и правила заполнения | параметры шаблона | проверенный PDF-лист`. Пока размеры и рисунок не сверены, статус — «шаблон не проверен», а не «по ГОСТ».

## Профильные стандарты

21.101 не закрывает оформление каждого раздела: выбрать и проверить действующие редакции ГОСТ 21.501 для АР/КЖ, 21.502 для КМ, 21.602 для ОВ, 21.601 для внутренних ВК, 21.110 для спецификаций; наружные сети и иные разделы требуют своих документов. Это направления поиска, не заявление обязательности всех стандартов.

Выход нормоконтроля: `лист/документ | пункт/форма | фактическое исполнение | дефект | исправление | повторная проверка`. Успешный экспорт, красивый штамп или заголовок «по ГОСТ» не закрывают проверку. Данный справочник не содержит готовых проверенных графических семейств рамок.
