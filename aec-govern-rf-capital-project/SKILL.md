# Управление жизненным циклом ОКС в РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Построй проверяемый маршрут объекта. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

## Полный цикл — для локальной задачи только зависимые пункты

0. Зафиксируй дату нормативного среза, регион, объект, вид работ и источник финансирования.
1. Классифицируй объект и выбери применимый правовой маршрут; не предполагай одинаковый порядок для всех ОКС.
2. Выдели применимые контрольные этапы: земля/планировка, ИРД, изыскания, ПД/РД, экспертиза, разрешение, строительство, исполнительная документация, надзор/ЗОС, ввод. Построй зависимости отдельно: ПД и РД могут разрабатываться параллельно; экспертиза, разрешения и надзор включаются по применимости, а не как обязательная линейная цепочка для любого объекта.
3. Для каждого ворота назначь основание, входы, ответственного, согласующих, результат и критерий завершения.
4. Свяжи требования, решения, документы, версии моделей и изменения единым журналом трассируемости.
5. Маркируй статус каждого элемента: подтверждено, в работе, допущение, просрочено, блокирует.
6. Перед переходом через ворота выполни юридическую, техническую и комплектностную проверку.

## Ограничения

- Не выдавай общий обзор за применимый конкретному объекту перечень без классификации и региональных процедур.
- Не считай разрешение, экспертизу, авторский надзор или членство в СРО обязательными во всех случаях; установи применимость по закону.
- Не подменяй юридическое заключение инженерным предположением.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай дорожную карту, матрицу ответственности, реестр нормативных оснований, комплектность ворот, журнал рисков и ближайшие обязательные действия.
