# Инженерные изыскания РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Свяжи изыскания с решениями проекта и рисками площадки. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

## Полный цикл — для локальной задачи только зависимые пункты

1. Классифицируй объект, этап, территорию изысканий, уровень ответственности и проектные решения, которым нужны данные.
2. Проверь исходные материалы, архивные результаты, давность, координатную/высотную систему и допустимость использования.
3. Сформируй задание и программу по применимым видам: геодезическим, геологическим, гидрометеорологическим, экологическим и специальным.
4. Назначь точки, глубины, лабораторные исследования, наблюдения, сезонность и контроль качества по расчётным рискам, а не только минимальному шаблону.
5. Проверь полевые материалы, протоколы, модели поверхности/геологии и технический отчёт.
6. Сопоставь выводы с фундаментами, земляными работами, водопонижением, сетями, защитой территории и охраной окружающей среды.
7. Оформи замечания, ограничения применимости и решение о приёмке.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай матрицу «проектное решение → требуемые данные», задание/программу, реестр материалов, проверку качества и заключение о достаточности изысканий.
