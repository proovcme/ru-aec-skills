# Исполнительная документация РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Веди комплект одновременно с работами. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

РД описывает проект, а не факт выполнения. Не создавай исполнительную схему без фактических данных и не имитируй акты, испытания или подписи.

## Полный цикл — для локальной задачи только зависимые пункты

1. Зафиксируй нормативный срез, объект, участников, применимость стройнадзора и формат документов.
2. Построй матрицу: работа → контроль → исполнительный документ → подписанты → срок до сокрытия.
3. Назначь единые ID конструкций, помещений, сетей, участков и осей.
4. Собирай документы качества материалов, результаты входного контроля и лабораторных испытаний.
5. Оформляй исполнительные схемы, акты скрытых работ, ответственных конструкций и участков сетей по факту.
6. Веди журналы, протоколы испытаний и пусконаладки с контролем дат, подписей и последовательности.
7. Сверь комплект с РД, фактическими объёмами, изменениями и исполнительной моделью.
8. Проведи аудит комплектности для надзора, ЗОС и ввода.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай матрицу исполнительной документации, реестр комплектности, перечень неподтверждённых работ и индекс передачи.
