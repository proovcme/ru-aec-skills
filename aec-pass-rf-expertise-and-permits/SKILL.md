# Экспертиза и разрешение на строительство

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Сначала докажи применимость процедуры. Для выполнения процедуры или полного аудита прочитай [методику](references/method.md) полностью; короткое объяснение по достаточным данным не требует запуска всей процедуры.

## Полный цикл — для локальной задачи только зависимые пункты

1. По классификации объекта определи необходимость и вид экспертизы изысканий, ПД и сметной стоимости; проверь специальные экспертизы.
2. Определи компетентную экспертную организацию и орган выдачи разрешения.
3. Сформируй входной комплект по действующему ГрК РФ и выбранной процедуре: постановление №145 для государственной экспертизы; постановление №272 и относящиеся к нему требования для негосударственной. Проверь применимость, актуальность, аккредитацию организации и регламент информационной системы.
4. Проведи предэкспертную проверку состава ПД по постановлению №87, ИРД, заверений, подписей и форматов.
5. Веди замечания как требования: текст → основание → затронутые документы → решение → новая ревизия → доказательство закрытия.
6. После положительного заключения собери комплект для разрешения на строительство и повторно проверь участок, параметры и полномочия заявителя.
7. Зафиксируй условия, сроки и параметры разрешения и передай их в план строительства.

## Ограничения

- Общий учебный обзор допускается; маршрут конкретного объекта требует проверки исключений и специальных признаков.
- Не считай негосударственную экспертизу допустимой во всех случаях.
- Не начинай работы без требуемого разрешения.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай дерево применимости, реестр входных документов, журнал замечаний, заключение о комплектности и карточку разрешения на строительство.
