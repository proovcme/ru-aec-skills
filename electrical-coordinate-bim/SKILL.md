# Координация ЭОМ

## Масштаб работы
Локальный вопрос решай по относящимся входам; не запускай полный раздел и не создавай пустые реестры. Аудит не разрешает менять модель. Допущения допустимы для концепции, но не заменяют подтверждение для строительства. Выдай результат, проверку и оставшиеся ограничения.

При назначении нормативного критерия или подтверждении соответствия прочитай [нормативный маршрут](../electrical-define-design-basis/references/normative-route.md); для арифметики с заданными входами это не требуется.

- Зафиксируй ревизии связей, координаты и уровни. Перед существенной разрешённой переработкой сохрани восстановимую версию; сначала проверь небольшой типовой узел.
- Моделируй источник → щит → цепь → приёмник; проверяй коннекторы, напряжение, фазы, расчётные параметры и принадлежность цепи. Видимый кабель/лоток не доказывает электрическую связность.
- Проверь заполнение/массу трасс, радиусы по кабелям, крепления и монтаж, разделение несовместимых сетей, вертикальные переходы, проходки и огнезаделки. Для противопожарных систем проверяй работоспособность кабельной линии как сборки, не только индекс кабеля.
- Щиты: реальные габариты, дверцы, фронтальный/задний доступ по исполнению, замена оборудования, вода/тепло и маршрут транспортировки.
- Параметры для ведомостей: устойчивая марка/ID, система, щит/цепь, тип, напряжение/фазы, нагрузки и единицы, кабель/длина и способ получения, уровень, ревизия/статус. Не подменяй ведомость только текстовыми выносками.
Выход: согласованная модель, проверка данных и геометрии, задания смежникам. Выдавай проёмы с ID преграды, размерами/отметками и резервом под конкретный узел, а не как уже согласованные отверстия.
