# Основа пожарной безопасности

## Масштаб работы
Локальный вопрос решай по относящимся входам; не запускай полный раздел и не создавай пустые реестры. Аудит не разрешает менять модель. Допущения допустимы для концепции, но не заменяют подтверждение для строительства. Выдай результат, проверку и оставшиеся ограничения.

Для нормативного решения прочитай [маршрут](references/normative-route.md).
- Установи вид работ, назначение частей здания, высоту в нормативном смысле, этажи/подземные уровни, площади и отсеки, людей и мобильность, конструктивную схему, степень огнестойкости и классы. Не назначай их по слову «офис».
- Отдели установленное от предложенного. Категории взрывопожарной опасности определяй для применимых помещений по веществам, количеству и процессам; не присваивай категорию серверной по названию.
- Сопоставь эвакуацию, ограничение распространения пожара, доступ пожарных подразделений, источники воды, необходимость СПС, СОУЭ, АУПТ, ДУ/подпора и электроснабжение защиты.
- Для каждой системы: условие применимости → основание → границы → ответственный раздел → входы/задания. Отсутствие точного адреса не мешает концепции, но не подтверждает подъезды, воду или местные условия.
- Не выдавай расчёт риска или СТУ за универсальный способ отменить требование. Установи законный путь обоснования.
Результат полного цикла: основа ПБ, карта применимости и открытые решения с влиянием на АР/КР/ОВ/ВК/ЭОМ. Это не подписанное заключение экспертизы.
