# СПС, СОУЭ и взаимодействие

## Масштаб работы
Локальный вопрос решай по относящимся входам; не запускай полный раздел и не создавай пустые реестры. Аудит не разрешает менять модель. Допущения допустимы для концепции, но не заменяют подтверждение для строительства. Выдай результат, проверку и оставшиеся ограничения.

При назначении нормативного критерия или подтверждении соответствия прочитай [нормативный маршрут](../fire-define-design-basis/references/normative-route.md); для арифметики с заданными входами это не требуется.

- Зафиксируй необходимость и тип систем, геометрию и назначение помещений, потолки/балки/полости, среды, помехи и эксплуатацию. Выбери принцип обнаружения и оборудование по действующим требованиям и документации производителя.
- Расстановка требует проверки покрытия, высот, препятствий, воздухораспределения и доступа. Не делай универсальную сетку извещателей; СОУЭ проверяй по слышимости/разборчивости и визуальному оповещению, не только по числу значков.
- Определи зоны контроля и оповещения, топологию, адресацию, ёмкость приборов, последствия единичной неисправности, питание и резерв. Рассчитай потребление по режимам, длительности и условиям АКБ; не выбирай аккумулятор только по сумме номинальных токов.
- Матрица причин и следствий: событие/зона → условие подтверждения → команда → устройство/система → состояние → обратная связь → отказ/ручной режим/сброс. Уточняй допустимые задержки по применимому требованию.
- Различай нормально открытые противопожарные клапаны, нормально закрытые дымовые и иные исполнения. Не командуй «закрыть всё» при пожаре; не отключай питание всех инженерных систем вместе с противопожарными.
- Расчёты ДУ и подпора передавай существующим hvac-design-smoke-exhaust и hvac-design-pressurization; пожарного водопровода — plumbing-design-fire-water. Эти зависимости загружай только по соответствующей задаче.
Выход: планы, схемы связей, адресная ведомость, расчёт питания, матрица алгоритмов и задания ЭОМ/ОВ/ВК. Проверяй сценарии и отказы; логическая проверка не равна проведённым натурным испытаниям.
