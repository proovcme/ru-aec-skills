# Аэродинамический расчёт воздуховодов

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Сделай расчёт воспроизводимым по каждому участку. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Зафиксируй версию схемы, расходы, материал, шероховатость, класс герметичности, ограничения по шуму и габаритам.
2. Раздели сеть на участки между точками изменения расхода, сечения или сопротивления.
3. Назначь начальные сечения и вычисли скорости.
4. Рассчитай линейные и местные потери по принятой методике и фактической геометрии фасонных элементов.
5. Определи критические пути отдельно для каждого вентилятора с границами всасывания/нагнетания и определением давления по references/method.md.
6. Учти фильтры, теплообменники, клапаны, шумоглушители, решётки и загрязнение в согласованном расчётном состоянии.
7. Сбалансируй параллельные ветви и сформируй доступные места измерения/регулирования.

## Контроль

- Не суммировать максимальные потери разных ветвей.
- Не использовать скорость как единственный критерий сечения.
- Учитывать утечки и системный эффект вентилятора только по подтверждённой методике, не произвольным запасом.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай таблицу участков, критические ветви, располагаемое/требуемое давление, балансировку и рабочую точку вентилятора.
