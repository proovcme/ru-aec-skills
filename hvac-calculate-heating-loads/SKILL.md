# Расчёт тепловых нагрузок

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Построй воспроизводимый тепловой баланс помещения. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

0. Зафиксируй нормативный срез, расчётный режим и климатические параметры по действующему СП 131 для конкретного пункта.
1. Определи внутренние температуры, режимы помещений, постоянных/временных людей и соседние температурные зоны.
2. Для каждой стены, крыши, перекрытия, пола, окна, двери и ворот получи конструкцию и рассчитай либо проверь приведённое сопротивление по действующему СП 50; зафиксируй источник материалов и коэффициентов.
3. Определи геометрию каждого ограждения: размеры, площадь нетто, ориентацию, угловое положение, отметку, контакт с наружным воздухом/грунтом/смежным объёмом и ID элемента BIM.
4. Замкни площади оболочки: не дублируй проёмы, вычитания и границы помещений.
5. Рассчитай основные и добавочные трансмиссионные потери по каждому элементу.
6. Рассчитай нагрев инфильтрационного и организованного наружного воздуха без двойного учёта с вентиляцией.
7. Учти только гарантированные теплопоступления, допустимые методикой для расчётного режима.
8. Сведи нагрузку по помещениям, зонам, системам и зданию; исследуй выбросы и несоответствия.

## Контроль

- Для тепловой защиты проверь применимость СП 50.13330.2024, для климатических данных — СП 131; уточни актуальную редакцию, изменения и область каждого документа.
- Не смешивай нагрузки отопления, вентиляции и ГВС.
- Не маскируй геометрическую или нормативную ошибку произвольным запасом.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай климатический паспорт, реестр ограждений и их сопротивлений, геометрическую ведомость, поэлементную таблицу теплопотерь, баланс составляющих, список допущений и нагрузки по уровням агрегации.
