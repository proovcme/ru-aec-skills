# Расчёт воздухообмена помещений

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Определи расчётный расход для каждого помещения. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

0. Зафиксируй нормативный срез и климатические параметры расчётных периодов по действующему СП 131.
1. Для каждого помещения зафиксируй назначение, постоянных и временных людей, сменность, графики присутствия и одновременность.
2. Отдельно зафиксируй технологические выделения, санитарный класс, категорию по взрывопожарной и пожарной опасности, класс зоны и ограничения на рециркуляцию/совмещение систем.
3. Определи расчётную геометрию: площадь, чистую высоту, объём, рабочую/обслуживаемую зоны, двери, переточные проёмы и связь с соседними помещениями.
4. Найди требования СП 60 и профильных документов здания в действующих редакциях.
5. Рассчитай раздельно санитарную норму, кратность, ассимиляцию вредностей, влаги и явного тепла, местные отсосы.
6. Сформируй случаи одновременности и выбери определяющий расход без необоснованного суммирования.
7. Назначь приток, вытяжку и перетоки; проверь движение воздуха между чистыми и загрязнёнными зонами.
8. Сведи баланс по помещениям, зонам, этажам, пожарным отсекам и системам.

## Контроль

- Показывай формулу, единицы, подстановку, источник коэффициентов и округление.
- Не принимай кратность как универсальную замену расчёту.
- Не допускай скрытого дисбаланса через двери и непредусмотренные щели.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай расчётные листы, сводную таблицу воздухообмена, схему перетоков, определяющие расчётные случаи и список исходных данных для систем вентиляции.
