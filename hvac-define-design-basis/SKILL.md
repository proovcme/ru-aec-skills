# Исходные данные ОВ для РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Сформируй проверяемую основу проекта. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

0. Зафиксируй объект, адрес/климатический пункт, стадию, границы, дату нормативного среза и версии входных моделей.
1. Составь нормативную карту: базовые СП/ГОСТ, документы по назначению здания, пожарной и промышленной безопасности.
2. Создай реестр помещений: функция, технологический процесс, постоянные и временные люди, сменность, режим, параметры среды и вредности.
3. Отдельно зафиксируй пожарный паспорт: функциональный класс, пожарные отсеки, категории помещений по взрывопожарной и пожарной опасности, классы пожароопасных/взрывоопасных зон и источник этих данных.
4. Получи климатические параметры по действующему СП 131 для конкретного пункта и всех расчётных периодов.
5. Создай реестр ограждений: составы, толщины, теплотехнические характеристики, условия эксплуатации, воздухопроницаемость и приведённые сопротивления по действующему СП 50.
6. Создай геометрический реестр помещений и оболочки: площади, высоты, объёмы, отметки, стены, покрытия, перекрытия, полы, окна, двери, ворота, ориентацию, углы и соседние среды.
7. Собери ТУ, пожарную концепцию, технологию, инженерные интерфейсы и BIM-требования; свяжи расчётные записи с ID помещений и элементов модели.
8. Для каждого параметра укажи источник, статус, владельца, дату и влияние отсутствия. Выпусти журнал допущений и запросов.

## Ограничения

- Не считать ссылку на норму проверенной без номера редакции/изменения и пункта.
- Не подменять отсутствующие исходные данные «типовыми» значениями без маркировки допущения.
- Не переносить решения с другого объекта без повторной проверки условий применимости.
- Не назначать самостоятельно категорию по взрывопожарной и пожарной опасности: получить её из раздела ТХ/ПБ либо оформить отсутствие как блокирующий запрос.
- Для конкретного расчёта проверь именно влияющие входы. Например, характеристики ограждений нужны для теплопотерь, но не блокируют аэродинамику ветви с известными расходом и геометрией. Предварительные расчёты допускаются с явными допущениями и границами; неподтверждённые влияющие входы не позволяют объявить окончательный результат проверенным.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай основу проектирования, реестры помещений, людей, пожарных характеристик, климата, ограждений и геометрии, нормативную матрицу, карту границ, журнал допущений и список данных для следующих расчётных процессов.
