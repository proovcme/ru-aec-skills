# Общеобменная вентиляция

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Преобразуй баланс помещений в работоспособные системы. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Прими таблицу воздухообмена, концепцию и пожарные границы.
2. Сгруппируй помещения по совместимости воздуха, режиму, этажности, эксплуатации и требованиям функциональных СП.
3. Выбери естественное, механическое или смешанное побуждение и докажи работоспособность во всех расчётных режимах.
4. Размести приточные и вытяжные устройства; проверь обслуживаемую зону и короткое замыкание потоков.
5. Проложи магистральную сеть, назначь места регулирования, очистки, теплоутилизации и шумоглушения.
6. Проверь воздухозабор/выброс, огнезадерживающие решения, транзит, герметичность и доступ обслуживания.
7. Передай сеть на аэродинамический расчёт и подбор оборудования.

## Контроль

- Не объединять несовместимые выбросы и зоны разных режимов без нормативного обоснования.
- Не считать размещение решётки доказательством воздухораспределения.
- Не использовать противодымную вентиляцию как обычную без отдельной допустимой логики.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай паспорт систем, схемы баланса и воздухораспределения, трассы, перечень регулирующих/пожарных элементов и задания смежникам.
