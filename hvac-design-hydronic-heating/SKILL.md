# Проектирование водяного отопления

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Свяжи нагрузку каждого помещения с гидравлически регулируемой системой. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Прими тепловые нагрузки, параметры источника и допустимые давления/температуры.
2. Выбери схему, зонирование, температурный график и способ регулирования.
3. Размести приборы и назначь мощность в фактическом температурном режиме.
4. Рассчитай расходы по приборам, ветвям, стоякам и зонам.
5. Подбери диаметры и рассчитай критические контуры с учётом арматуры и оборудования.
6. Назначь балансировку, авторитет регулирующих клапанов, удаление воздуха, опорожнение, компенсацию и защиту.
7. Проверь статическое/рабочее давление и взаимодействие с ИТП или источником.

## Контроль

- Не использовать паспортную номинальную мощность прибора без пересчёта на проектные температуры.
- Не принимать диаметры поставщика без проверяемого расчётного журнала.
- После изменения нагрузки или трассы пересчитывать затронутый контур.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай схему зон, ведомость приборов, таблицу участков, критические контуры, настройки арматуры и BIM-параметры.
