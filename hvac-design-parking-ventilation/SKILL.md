# Вентиляция автостоянок

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Разделяй санитарный режим и пожарные сценарии. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Определи тип автостоянки, геометрию, вместимость, режим въезда/выезда, тип транспорта, рампы и сообщающиеся помещения.
2. Проверь СП 113, СП 60 и санитарные требования в актуальных редакциях.
3. Рассчитай общеобменный расход по применимой методике для загрязнений и эксплуатационного сценария.
4. Раздели зоны и системы по пожарным отсекам, уровням и допустимой площади обслуживания.
5. Размести забор/удаление воздуха, исключая застойные зоны и перенос загрязнений в здание.
6. Определи ступени производительности, газовый контроль, алгоритмы обычного режима и блокировки с пожарной автоматикой.
7. Передай пожарные сценарии в `$hvac-design-smoke-exhaust` и `$hvac-design-pressurization`.

## Контроль

- Не использовать фиксированный процент движения автомобилей без проверки действующей методики и ТЗ.
- Не суммировать общеобменный и пожарный расходы автоматически.
- Проверить выброс относительно воздухозаборов, окон и территории.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай расчётные сценарии, зоны, баланс, алгоритм управления, размещение датчиков и задания для оборудования/BIM.
