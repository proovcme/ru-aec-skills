# Выпуск документации ОВ в РФ

Для короткой оценки готовности по описанию прочитай только [предварительную проверку](../aec-develop-rf-design-documentation/references/release-triage.md) и используй её вместо полного порядка ниже. Для фактического выпуска, работы с файлами или нормативного заключения выполняй полный применимый маршрут.

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Обеспечь одну версию инженерного решения во всех документах. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Определи комплект по договору, ПП РФ №87, ГОСТ СПДС, требованиям экспертизы и стадии.
2. Свяжи исходные данные, концепцию, расчёты, оборудование, модель, графику и спецификацию сквозными идентификаторами.
3. Подготовь текстовую часть с обоснованиями, параметрами, балансами, пожарными решениями, энергоэффективностью и эксплуатацией.
4. Подготовь планы, разрезы, схемы и узлы в детализации стадии.
5. Сформируй спецификации/ВОР из проверяемых данных и согласованной методики подсчёта.
6. Выполни перекрёстную проверку расходов, мощностей, марок, сечений, отметок, питания, автоматики и заданий.
7. Зафиксируй ревизию, изменения, допущения, исключения и открытые действия.

## Контроль

- Проверить актуальную редакцию ПП РФ №87 и применимых ГОСТ перед выпуском.
- Не включать неподтверждённые нормативные ссылки и шаблонные фразы.
- Не выпускать расчёты систем противопожарной защиты без требуемой проверки.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай реестр выпуска, перечень файлов, контрольный лист качества, журнал изменений и список незакрытых рисков.
