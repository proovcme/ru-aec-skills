# Концепция систем ОВ для РФ

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Выбирай систему по функции здания и ограничениям проекта. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Зафиксируй основу проекта и расчётные режимы со статусом. Для концепции допустимы обозначенные предположения с оценкой влияния; не выдавай их за утверждённые исходные данные.
2. Раздели объект на зоны по назначению, графику, микроклимату, высоте, пожарным отсекам и эксплуатации.
3. Сформируй жизнеспособные варианты систем и сравни их по обязательным критериям.
4. Проверь размещение оборудования, шахт, воздухозаборов, выбросов, источников тепла/холода и сервисных зон.
5. Выбери решение, зафиксируй отклонённые альтернативы и причины.
6. Передай границы систем, режимы и нагрузки в расчётные процессы.

## Ограничения

- Не объявлять решение нормативным только потому, что оно типовое.
- Не объединять зоны с несовместимыми загрязнениями, режимами или пожарными требованиями.
- Не выбирать оборудование на стадии концепции вместо определения его расчётной функции.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай матрицу вариантов, принятую концепцию, схемы зонирования, перечень согласований и BIM-следствия.
