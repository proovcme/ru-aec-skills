# Подбор вентиляционного оборудования

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Подбирай оборудование по рабочей точке и всем режимам. Прочитай [references/method.md](references/method.md) полностью.

## Полный цикл — для локальной задачи только зависимые пункты

1. Сформируй техническое задание на подбор с расчётными и предельными режимами.
2. Определи рабочую точку вентилятора с учётом сопротивления системы и системного эффекта.
3. Рассчитай тепловую/холодильную мощность секций и проверь параметры воздуха по процессу обработки.
4. Проверь фильтрацию по действующей классификации, загрязнение и конечное сопротивление.
5. Проверь рекуперацию, обмерзание, защиту водяного нагревателя, конденсат, автоматику и резервирование.
6. Проверь шум, вибрацию, энергоэффективность, электропитание, массу, габариты, секционность и сервисные зоны.
7. Сравни предложения по одинаковым исходным данным и верни выбранные параметры в расчёт/BIM.

## Ограничения

- Не принимать номинальную производительность как подтверждение рабочей точки.
- Не использовать устаревшую маркировку фильтра без сопоставления с действующим стандартом.
- Не заменять расчёт оборудования коммерческим подбором поставщика.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай опросный лист, сравнительную таблицу, график рабочей точки, перечень автоматики, замечания и подтверждённые BIM-параметры.
