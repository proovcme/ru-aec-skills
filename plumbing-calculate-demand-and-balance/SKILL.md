# Water Demand and Balance

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Определи расходы по категориям потребителей и расчётным периодам, сохраняя происхождение каждой величины.

## Полный цикл — для локальной задачи только зависимые пункты

1. Раздели потребителей по назначению, режиму и нормативной категории. Не объединяй группы с различными графиками или удельными показателями без обоснования.
2. Проверь количество пользователей, сменность, загрузку, санитарные приборы, технологические циклы, полив, уборку и иные регулярные или периодические нужды.
3. Выбери действующую методику для секундного, часового и суточного расчёта. Зафиксируй редакцию нормы, таблицу/формулу, исходные единицы и область применимости.
4. Рассчитай отдельно холодную воду, горячую воду, общий расход и стоки. Учитывай одновременность по методике, а не простым сложением номиналов приборов.
5. Составь водный баланс: поступление, потребление, безвозвратные расходы, повторное использование, бытовой/производственный/дождевой сброс. Объясни допустимые небалансы.
6. Сформируй расчётные случаи для ввода, счётчика, насосов, нагрева воды, магистралей и выпусков. Не подменяй один временной максимум другим.
7. Проведи sanity checks: расход на пользователя, отношение пиков к среднему, согласованность количества приборов и людей, соответствие лимитам подключения.

## Calculation record

Показывай формулу символически, затем подстановку, единицы и результат. Не округляй промежуточные величины чрезмерно. Отделяй нормативный коэффициент, проектное допущение и результат расчёта.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай реестр потребителей, таблицу расчётных расходов по периодам, водный баланс, governing cases и список параметров для гидравлики и технических условий.
