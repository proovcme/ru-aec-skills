# Plumbing BIM Coordination

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Используй модель для доказательства трассируемости, уклонов, доступа и интерфейсов.

## Полный цикл — для локальной задачи только зависимые пункты

1. Зафиксируй координаты, уровни, единицы, классификацию систем, идентификаторы, зоны ответственности, LOD/LOI и правила обмена.
2. Моделируй по зависимости: точки подключения и приёмники → оборудование → стояки/выпуски → магистрали → ответвления → арматура и детали.
3. Для самотечных сетей веди контроль отметок от фиксированной downstream-точки. Сохраняй уклоны, доступ к прочистке и строительную высоту при каждом обходе.
4. Проверяй фактические наружные габариты труб, изоляции, фитингов, уклонов, монтажных и сервисных зон; не полагайся только на осевую коллизию.
5. Создавай задания смежникам с системой, координатами, отметкой, габаритом, допуском, огнестойкостью/герметизацией, статусом и владельцем.
6. Координируй с HVAC подпитку, водоснабжение оборудования, дренаж и конденсат; фиксируй расход, качество, температуру, давление, режим и санитарный разрыв каждого интерфейса.
7. Решай коллизии по физическим ограничениям: сначала безопасность людей и несущих конструкций; далее самотёк и фиксированные подключения → крупные сети → обслуживаемое оборудование → гибкие напорные линии. После изменения проверяй расчёт и задания.

## Checks

- Не считать геометрически подключённый коннектор доказательством правильной системы.
- Не размещать отверстие без запаса на изоляцию, монтаж, перемещения и герметизацию.
- Не подтверждать готовность модели к строительству с неопределёнными системами, дублирующимися марками или неподтверждёнными отметками выпусков.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай модельный план, реестр интерфейсов, задания смежникам, журнал коллизий и список изменений для повторного расчёта.
