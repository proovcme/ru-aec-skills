# Internal Fire Water Design

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Считай этот skill safety-critical. Проектное решение требует действующей пожарной концепции и нормативов; объяснение или перечень недостающих данных не требует выдумывать эти исходники.

## Полный цикл — для локальной задачи только зависимые пункты

1. Получи утверждённые категории здания, пожарные отсеки, высоты, сценарии пожара, требуемые расходы/струи, продолжительность, надёжность и взаимодействие с автоматическим пожаротушением.
2. Определи границы систем, допустимость общего ввода или сети с иными потребителями, зонирование по давлению и требования к независимым путям подачи.
3. Размести устройства так, чтобы расчётная зона покрытия подтверждалась геометрически с учётом перегородок, дверей и доступного маршрута.
4. Построй гидравлическую модель наиболее неблагоприятного одновременного сценария. Проверь остаточное давление, потери, предельные давления и доступный внешний источник.
5. Сформируй duty point насосов и требуемый запас воды. Определи резервирование, тестовую линию, дренаж, защиту от недопустимого давления и безопасное обслуживание.
6. Разработай cause-and-effect: пуск, контроль положения арматуры, сигналы состояния/неисправности, электропитание, диспетчеризация и действия при отказе.
7. Согласуй отверстия, помещения, питание, автоматику, пожарные преграды и наружное пожарное водоснабжение.

## Non-negotiable checks

- Не переносить расходы, давления и радиусы действия из другого объекта.
- Не считать графическое покрытие доказанным без проверки фактического пути.
- Не завершать решение без проверки профильным специалистом, если того требует законодательство, договор или уровень риска.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай сценарии, гидравлические исходные данные и результаты, карту покрытия, duty points, cause-and-effect, интерфейсы и список обязательных проверок.
