# Plumbing Sizing and Equipment Selection

Выполняй только запрошенный объём и зависимые проверки; требуй влияющие входы. Аудит не разрешает изменения. Вывод по описанию не означает проверку файлов.

Для задач РФ нормативный вывод подтверждай пунктом, применимой редакцией и проверкой. При установлении нормативной основы или подтверждении соответствия прочитай [общий протокол](../aec-govern-rf-capital-project/references/normative-workflow.md). Для расчёта по заданным данным или выявления явного противоречия полный нормативный аудит не нужен; нормативную допустимость при этом не объявляй.

Связывай каждый размер и подбор с расчётным случаем и рабочей точкой.

Даже для локальной проверки показывай исходные величины, единицы, формулу и источник коэффициентов; не смешивай давление и напор без плотности и перевода единиц.

## Полный цикл — для локальной задачи только зависимые пункты

1. Зафиксируй расчётную версию влияющих расходов, схемы, отметок, материалов, температур и внешних параметров. Предварительный подбор допустим с явными допущениями и пересчётом после уточнения.
2. Для напорной сети выдели участки, расходы и критический путь. Рассчитай трение, местные сопротивления, геодезическую составляющую и требуемое остаточное давление.
3. Для самотечной сети проверь расход, диаметр, уклон, наполнение, скорость самоочищения, пропускную способность стояков и вентиляцию. Не применяй критерии напорной сети.
4. Подбери счётчик в рабочем диапазоне и проверь потерю давления, чувствительность, режимы малых/пиковых расходов, условия монтажа и требования оператора.
5. Подбери насос по фактической кривой системы и диапазону режимов. Проверь кавитационный запас, минимальный расход, регулирование, резервирование, переходные процессы и максимальное давление.
6. Определи полезный объём баков/приямков по притоку, цикличности, резерву и аварийному времени. Не используй геометрический объём как полезный без учёта уровней.
7. Сравни предложения производителей по duty point, материалам, сертификации, шуму, энергии, габаритам и обслуживанию.

## Change control

После изменения расхода, отметки, материала, трассы или оборудования пересчитай зависимые участки и пути; при изменении распределения расходов или рабочей точки проверь сеть в согласованном режиме, не только участки по ходу потока.

## Результат

Для локальной задачи — только затронутые результаты, допущения и проверка, без пустых/повторных реестров. Для полного цикла:

Выдай таблицу участков, гидравлический профиль, критические пути, карточки duty point, проверку оборудования и данные для BIM/спецификаций.
